# StudyOS — User Flow

## 1. First Launch

```text
Open StudyOS
   ↓
Create/Sign in
   ↓
Create first subject
   ↓
Add chapters
   ↓
Add exam date
   ↓
Set available study time
   ↓
Dashboard
```

## 2. Daily Flow

```text
Open Dashboard
   ↓
See today's plan
   ↓
Start highest-priority task
   ↓
Study
   ↓
Mark task complete
   ↓
Update confidence if relevant
   ↓
Planner recalculates
```

## 3. Chapter Completion

```text
Open Chapter
   ↓
Mark Completed
   ↓
Set confidence
   ↓
Create revision schedule
   ↓
Dashboard receives future revision tasks
```

## 4. Revision Flow

```text
Revision becomes due
   ↓
Appears in Daily Plan
   ↓
Review chapter
   ↓
Rate difficulty/confidence
   ↓
Calculate next interval
   ↓
Schedule next revision
```

## 5. Error Flow

```text
Open chapter
   ↓
Add error
   ↓
Select mistake type
   ↓
Describe mistake
   ↓
Add correct method
   ↓
Save
```

Subject-level flow:

```text
Subject
   ↓
Error Journal
   ↓
All errors from all chapters
   ↓
Filter by chapter/type/date
```

## 6. Multiple Exams

```text
Create Exam A
Create Exam B
Create Exam C
      ↓
Planner evaluates all active exams
      ↓
Prioritizes nearest/most urgent exam
      ↓
Allocates available time
      ↓
Daily Plan
```

## 7. Exam Completion

```text
Exam finished
   ↓
Mark exam completed
   ↓
Preserve history
   ↓
Remove preparation priority
   ↓
Recalculate active exams
   ↓
Generate new plan
```

## 8. Manual Override

```text
Daily Plan
   ↓
User changes available time
OR
User skips/completes task
   ↓
Recalculate
   ↓
Updated plan
```
