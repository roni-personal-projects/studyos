# StudyOS — Roadmap

## Phase 0 — Foundation

- Project setup
- Supabase setup
- Authentication
- Database migrations
- Base UI system
- Responsive shell

## Phase 1 — Core MVP

- Subjects
- Chapters
- Chapter status
- Confidence
- Multiple exams
- Exam/subject relationships
- Syllabus progress
- Dashboard
- Daily tasks

## Phase 2 — Learning Engine

- Revision scheduling
- Revision history
- Difficulty/confidence feedback
- Exam-aware prioritization
- Available-time allocation
- Automatic plan regeneration

## Phase 3 — Error Journal

- Chapter error journal
- Subject aggregated error journal
- Error types
- Filters
- Review tracking

## Phase 4 — Polish

- Mobile UX
- Loading states
- Empty states
- Error handling
- Accessibility
- Unit tests
- E2E tests
- Performance improvements

## Phase 5 — Optional

Only build if personally useful:
- Notifications
- Study timer
- Weekly summaries
- AI recommendations
- PDF/OCR syllabus import
- Flashcards
- Calendar integration

## Explicitly Avoid for Now

- Social features
- Leaderboards
- Public profiles
- Teacher accounts
- Full AI tutor
- Complex gamification
- Native mobile app

## Definition of Done

StudyOS is ready for personal use when the user can:

1. Add all subjects.
2. Add all chapters.
3. Add multiple exams.
4. Set daily available time.
5. Open the dashboard.
6. Follow the generated plan.
7. Complete chapters.
8. Receive automatic revision dates.
9. Log mistakes.
10. Review subject-wide errors.
11. Finish an exam and have the planner automatically reprioritize remaining work.
